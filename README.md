# iTracX

iTracX est une application web statique de suivi local de budget, patrimoine, portefeuilles et tâches.

## Déploiement GitHub Pages

Le site est prêt à être servi depuis la racine du dépôt :

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- icônes et assets SVG/PNG

Dans GitHub Pages, choisir la branche `main` et le dossier `/ (root)`.

## Installation mobile

Une fois publié en HTTPS via GitHub Pages, ouvrir l'URL sur mobile puis utiliser l'option du navigateur :

- iOS Safari : Partager -> Ajouter à l'écran d'accueil
- Android Chrome/Edge : menu -> Installer l'application
